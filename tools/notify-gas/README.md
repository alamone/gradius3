# ログイン申請の通知・承認・管理画面（Google Apps Script）

配布ページの Google ログイン（Firebase Authentication、プロジェクト `gradius3-login-41798`）の申請を扱う。Firebase は Spark（無料）のままでよい。

- **新しい申請** → 管理者にメール。メールの「承認する／却下する」リンクを開いてボタンを押すと決まる（Firebase の管理画面を開かなくてよい）。
- **自動承認**: 管理画面の一覧に入れた Google アカウント（ログインに使うメールアドレス）が申請したら、すぐ承認する。
- **承認したら** → 本人に「見られるようになりました」とメール（Firebase の管理画面で `status` を `approved` に変えた場合も同じ）。
- **管理者の登録**: 管理画面の「管理者」に入れた Google アカウントの人だけが「共同作業のまとめ」（status.html）を開ける（Firestore の `admins/{メールアドレス}`）。管理者は配布ページも自動で承認。
- **管理画面**（あなたの Google アカウントだけが開ける）: 申請者の一覧（承認待ち・承認・却下・すべて）、申請日時・決めた日時と方法・決めた人・最後のログイン、Twitter（X）のアカウントとコメントの記入、承認・却下・承認待ちに戻す、自動承認の一覧。
- データ: 申請は Firestore の `users/{uid}`（本人が作る）。Twitter・コメント・決めた記録は `admin_notes/{uid}`（ルールに無いのでページからは読めない＝本人には見えない）。ルールは `docs/dev/firebase/firestore.rules`。
- 5分ごとに確認する。Firestore の読み取りは無料の範囲（1日5万回）に収まる（申請者が百数十人までなら余裕）。

## 設定（1回だけ・パソコン推奨・15分）

Firebase のプロジェクトを作った **Google アカウント**で行う。前に作った Apps Script のプロジェクトがあれば、それをそのまま使ってよい。

0. **Firestore のルールを更新する**: Firebase の管理画面 → Firestore Database →「ルール」に、`docs/dev/firebase/firestore.rules` の中身を貼り付けて「公開」（管理者の一覧 `admins` を読めるようにする部分が増えた）。

1. https://script.google.com でプロジェクトを開く（無ければ「新しいプロジェクト」）。
2. コードを全部消して、このフォルダの [Code.gs](Code.gs) の中身を貼り付けて保存。先頭の「設定」の `PAGE_URL`（承認した人に案内するページ）を確かめる。
3. 左の歯車「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック → `appsscript.json` を [appsscript.json](appsscript.json) で置き換えて保存。
   - 同じ画面の「スクリプト プロパティ」に、前の方式の**サービスアカウントの鍵（private_key など）があれば削除**する。
   - 左の時計「トリガー」に前の `sendApprovalMail` があれば削除する。
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」→ 次のユーザーとして実行「自分」・アクセスできるユーザー「**自分のみ**」→「デプロイ」→ 許可を求められたら許可（「確認されていません」と出たら「詳細」→「移動」）。
   - 出てきた **ウェブアプリの URL** が管理画面。ブックマークしておく。
5. 関数 **`setup`** を選んで「実行」。承認待ちがあれば、承認リンク付きの一覧が1通届く。
6. 関数 **`testMail`** を実行して、メールが届けば完了。
7. 管理画面の「管理者」に3人の Google アカウントを入れて保存。共同作業のまとめ https://hknroms.github.io/gradius3/status.html に、その人たちだけが入れることを確かめる。

コードを直したときは「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」→「デプロイ」（URL は変わらない）。

## うまくいかないとき

- 「Firestore（403）」で `has not been used in project` などと出る: 歯車「プロジェクトの設定」→「Google Cloud Platform（GCP）プロジェクト」→「プロジェクトを変更」→ プロジェクト番号 **570590177142** を入れる。その後もう一度 `setup`。
- 管理画面が「Google ドライブのファイルを開けません」になる: ブラウザに複数の Google アカウントでログインしていて、最初のアカウントが作った人と違う。作った人だけでログインした別のブラウザ（またはシークレットウィンドウ）で開く。
- 最後のログインが出ない: 表示だけの情報なので、出なくても他は動く。
- 通知先を変えたい: Code.gs の `ADMIN_EMAIL`。却下も本人に知らせたい: `NOTIFY_REJECTED = true`。
- 止めたい: 左の時計「トリガー」で `check` を削除。
- コードを直したら、このフォルダにも反映する（リポジトリが正）。
