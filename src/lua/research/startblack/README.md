# START 表示の間の地形を隠す（#20 の続き、2026-10-29）

メニューから面の途中のエリアで始めると、START 表示の間に描きかけの地形が見えていた。純正の「死んで再開」は真っ黒。

## 分かったこと

- 純正は死んで再開するとき（`$3B74`：状態を 1 にする所）に `$414E` を呼び、地形・背景のパレット
  **$20〜$27・$30〜$37（`$80400〜$804FF`・`$80600〜$806FF`）を 0 にする**。START 表示の間はこのまま 0 なので地形が見えない。
  プレイに入ると（状態4で `$400a0` を 0 に戻すので）開始位置までのパレットの出来事がプレイの2フレーム目（`$E428`）にまとめて入り直す。
- 改造の ShPal（v0.4.17、START 表示の間もパレットの出来事 `$E318` を回す）は、この 0 を埋め直していた。
  そのため、メニューから面の途中で始めたときだけでなく、**改造プレイで死んで再開したときも** START 表示の間に地形が見えていた。
- 直し方：ShPal の最後で `$414E` を呼ぶ。ただし「その人の最初の START（MB_PEND のその人の bit が立っている）で、
  メニューで選んだ開始位置 `$103f1e` が 0（面の最初）」のときは呼ばない（純正のメニューを出さない START と同じく星が見える）。

## 確かめ方

```bash
H=<リポジトリ>/src/lua/research/startblack
bash $H/allareas.sh <直す前の mame フォルダ> 前          # 1〜10面の全エリア（56）。面を並べると絞れる: … 前 3 8
bash $H/allareas.sh <直した後の mame フォルダ> 後
python3 $H/compare.py 前 後 一覧.png                    # 一覧.png は START 表示の画面（左が前・右が後）
```

- `shots.lua`: 状態2（START 表示）・5（プレイ）に入ってから REL フレーム後の画面とパレットRAM。`st.log` に状態の変化。
- 純正の「死んで再開」と比べるとき：`G3RUN=../escape10/genstart.lua NEXT=../../g3run.lua STG=3 PROG=0f81` で純正を 3面の途中から始め、
  `HOLDK="1900:U:300,1900:L:300"` で地形にぶつけて死ぬと、2回目の状態2 が「死んで再開」（`s2_2_040`）。

## 結果（2026-10-29、MAME 0.289）

対照：直す前（main 5bee3df）と直した後を、同じ入力で比べた。

- START 表示（状態2 の 40 フレーム目）
  - 面の途中のエリア 46 か所：直す前は 34 か所で地形が出ていた（黒くない画素 2,100〜57,500。ほかの 12 か所は始まる所に地形が無く星だけで 797）→ 直した後はすべて 709 画素（START の字と星の点だけ）。地形・背景のパレットはすべて 0。
  - 純正の「死んで再開」（3面 F 付近）の START 表示とは 19 画素の違いだけ（星のまたたき＝パレット $27 の位相など）。
  - 面の最初（エリア A）10 か所：直す前と画面が同じ。
- プレイ（状態5 の 60・300・600 フレーム目）：47 か所は 3 枚とも画面が同じ。違ったのは
  - 3面 D：パレット $24（面で使わない色。直す前はメニューの名残りの暗い色 `$0001〜$1028`、直した後は 0）を使う点が 12,000 画素ほど。ほとんど黒なので見た目の差はごくわずか。純正の「死んで再開」も 0。
  - 5面 B〜❷・7面 B〜❶：60 フレーム目だけ 20 画素ほど（星のまたたき $27 の位相）。300 からは同じ。
  - 8面 C：300・600 フレーム目に天井・床の植物の揺れの位相が1段ずれる。パレットの違いは無い。`$414E` の代わりに「同じ処理時間がかかり、レジスタは直す前と同じ」形（`$414E` を `$E318` の前に呼ぶ）にしても同じずれ方になるので、START 表示の間の処理時間の差によるもの（ずれ方はエミュレータのタイミングしだいで、実機でも決まった位相ではないはず）。
- メニューを出さない START（死んで再開も）：直す前と画面がすべて同じ（ShPal は改造プレイだけ）。
- 改造プレイで死んで再開：面の途中（3面 F）・面の最初（3面 A）とも START 表示が真っ黒になった（直す前は地形・星が見えていた）。
