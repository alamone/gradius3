純正313版ベースの改造（隠しメニュー・面選択・ボスラッシュ・キューブラッシュ ほか）。このページはパッチ（差分）だけを配布しています。ROMデータは含みません。

ステレオ化 聞き比べ（試作）

FM音源8チャンネルの左右の振り分けを変えたもの（ドラム・音声のPCMは中央）。1面 → 3面 → 10面のBGMを20秒ずつ。 ボタンを押すとすぐ再生し、再生中に別のボタンを押すと同じ位置から切り替わります。左右の分かれ方が分かるよう、ヘッドホン推奨。
四角は FM のチャンネル0〜7（左／右／灰色＝中央）。録音はMAMEに左右出力を付け足して作成（実機・通常のMAMEはモノラル）。

MAME用 zip を作る

  1. お手持ちの純正ROMをまとめてドロップしてください（zipのまま・zipの中のzip・バラのファイル、どれでも可）。
    必要なもの：MAME用 gradius3 一式（R版） と 313版メインROM 2本（945_313.f15 / 945_312.e15）。ファイル名ではなく中身（CRC）で判別します。
  2. そろったら「作成」を押すと、MAMEの roms フォルダにそのまま入れられる zip がダウンロードされます。
    出力するセットは gradius3j（新しいMAME（0.289 など）では「Japan, version 3, newer」＝313版として起動。おすすめ）、gradius3（「World, version R」として起動）、古いMAME向けの gradius3j（「Japan, program code S」）から選べます。中身の改造ROMはどれも同じで、ファイル名だけが違います。
ROMはお使いのブラウザの中だけで処理され、どこにも送信されません。元の gradius3.zip / gradius3j.zip は上書きしないよう、別の場所に控えてください。MAMEは「チェックサム不一致」の警告を出しますが動作します。

使い方（ゲーム内）

  • ゲーム中でないとき：レバー上＋A（押す順番は自由）→ 両方離す → レバー下＋A → 両方離す で隠しメニュー解除。下から始めて上で終えるとロック。各段階3秒以内。300秒放置で自動ロック。
  • 解除中にクレジットを入れて 上＋START で既定値、下＋START で前回の設定のメニュー。レバーを入れずにSTARTなら純正どおり。
  • メニューは上下で選択、左右で変更、STARTで開始、SHOT2（または BACK TO DEMO）でデモに戻る。開始後は装備選択画面になります。
  • 改造モードのプレイ中：START＝装備（スピード2・ミサイル・レーザー・オプション4・バリア）、SHOT＋START＝レーザーの代わりにダブル、MISSILE＋START＝スピード2・ミサイル・オプション2。NORMALは1ゲーム1回、キューブ/ボスラッシュは無制限。START長押しでポーズ（CONTINUE / GAME OVER）。
