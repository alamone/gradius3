グラディウスIII 改造ROM パッチ

純正313版ベースの改造（隠しメニュー・面選択・ボスラッシュ・キューブラッシュ ほか）。このページはパッチ（差分）だけを配布しています。ROMデータは含みません。

ステレオ化 聞き比べ（試作）

▶ ステレオの聞き比べはこちら全35曲・10パターンをボタン1つで切り替え。チャンネルごとの細かい設定と、曲ごとの評価の記録もできます（ヘッドホン推奨）

キューブラッシュの解析

▶ キューブラッシュの解析結果はこちら高さの決まり方・2880通りの並び（H／S／T）・処理落ちによるずれ（LAG）・くっつく判定。H・S・T を選んで99個の並びを見られます

使い方（ゲーム内）

隠しメニューに入る

  • クレジットを入れて、レバー上＋START で既定値のメニュー、レバー下＋START で前回の設定のメニューに入ります。レバーを入れずに START なら純正どおりに始まります。
  • 解除／ロックのコマンド（ゲーム中でないとき：レバー上＋A → 両方離す → レバー下＋A → 両方離す で解除、下から始めて上で終えるとロック。各段階3秒以内。300秒放置で自動ロック）は、今は一時停止中です。常に解除された状態なので、コマンドなしでメニューに入れます。

メニュー

  • 上下で項目を選び、左右で値を変え、START で開始します（メニューからデモには戻りません）。開始後はタイプ選択（ビギナーは選べません）と装備選択の画面になります。
  • 項目：INVINCIBLE（無敵）／MODE（NORMAL・CUBE RUSH・BOSS RUSH）／LOOP（周回）／面とエリアの表／CUBE HEIGHT・SHIFT・TYPE（キューブラッシュの並び）／SHD COLOR（シールドの色）／HUNTER NEXT・HUNTER TIME（オプションハンター）／SPEED（開始時のスピード）／CAPSULE（開始時のカプセルゲージの位置）。

プレイ中の装備コマンド（START を短く押す）

  • START：スピード2・ミサイル・レーザー・オプション4・シールド
  • ショット＋START：レーザーの代わりにダブル
  • ミサイル＋START：ノーマルショットのフル装備（レーザー・ダブルなし）
  • ショット＋ミサイル＋START：スピード2・ミサイル・オプション2
  • NORMAL は1ゲーム1回、キューブラッシュ・ボスラッシュと無敵中は何回でも使えます。装備は足すだけなので、レーザー・ダブルを持っている状態からノーマルショットには戻りません。

ポーズメニュー（START を約1秒押し続ける）

  • 上下で選び、ON/OFF の項目は左右かショットで切り替え、START（またはショット）で再開します。ポーズ中はゲームのタイマーも止まるので、キューブの並びはずれません。
  • CONTINUE（再開）／GAME OVER（やめる）／INVINCIBLE（無敵）／RANK DISP（ランクを表示）／CUBE INFO（キューブラッシュの並び・ずれを表示。ハイスコアと 2P の場所に出ます）／CUBE COLOR（飛んでくるキューブを反応する位置で色分け）。RANK DISP・CUBE INFO・CUBE COLOR は、メニューから始めるたびに OFF に戻ります。

キューブラッシュ

  • 残機はディップスイッチの残機＋4。キューブが1個くっつくたびに 1000点（ハイスコア・ランキング・残機の増加には影響しません）。

MAME用 zip を作る

  1. お手持ちの純正ROMをまとめてドロップしてください（zipのまま・zipの中のzip・バラのファイル、どれでも可）。
    必要なもの：MAME用 gradius3 一式（R版） と 313版メインROM 2本（945_313.f15 / 945_312.e15）。ファイル名ではなく中身（CRC）で判別します。
  2. そろったら「作成」を押すと、MAMEの roms フォルダにそのまま入れられる zip がダウンロードされます。
    出力するセットは gradius3j（新しいMAME（0.289 など）では「Japan, version 3, newer」＝313版として起動。おすすめ）、gradius3（「World, version R」として起動）、古いMAME向けの gradius3j（「Japan, program code S」）から選べます。中身の改造ROMはどれも同じで、ファイル名だけが違います。
ROMはお使いのブラウザの中だけで処理され、どこにも送信されません。元の gradius3.zip / gradius3j.zip は上書きしないよう、別の場所に控えてください。MAMEは「チェックサム不一致」の警告を出しますが動作します。
