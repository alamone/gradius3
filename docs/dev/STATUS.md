## 4. 決定事項・回答済み

- 曲番号 80 は「武器選択」の曲ではなく、1面の最初のスタート（武器選択の後）でだけ鳴る出だしの音（2026-10-26 ユーザー）。ボスラッシュの1面ボスでこれが鳴る件は #23。
- BrSkip（ボスラッシュの撃破後スクロールを飛ばす）は残し、切り替えをスクロールが動き出す直前まで遅らせる（2026-10-26、#22）。
- 通常プレイは純正どおり。改造機能は MB_RUN（メニュー経由の開始）で有効になる。`LOCK_SUSPEND = True`。
- パッチは **BPS のみ**。公開は最新と1つ前の版だけ（`tools/release.py` が自動で古い版を消す）。更新履歴の文章は全部残す。
- Origins（別の改造版）の痕跡を残さない（参考にするのは可）。
- クレジット表示は今のままでよい。
- MAME4droid（0.289）: UI の一覧からは改造ROMを起動できない（SHA-1 が純正と違い「チェックサムが正しくない」で止まる。ファイル加工では回避不可）。回避案: Daijishou / ES-DE などのフロントエンドから直接起動、または「アプリで開く」（いずれも未検証）。ROM フォルダは 設定 → General → Change ROMs path。
- 実機（基板）では MAME の照合は無い。ゲーム自体の起動時 ROM チェックはメイン・サブ・サウンドとも合計値を補正済み（実機未検証）。
- PS5 コントローラー（USB）を Windows の MAME で使う方法: Tab → Input (this Machine)、ダメなら DS4Windows / Steam 入力。

## 6. 配布ページのログイン（2026-10-26〜）

- 配布ページを Google ログインの内側に置いた（ユーザーが設定。Firebase Authentication、プロジェクト `gradius3-login-41798`、Spark プラン）。
- 申請: ログインした人が Firestore の `users/{uid}` に `status: "pending"` で自分の申請を作る。**承認は管理者が Firebase の管理画面で `status` を `approved` に変える**。ルールは `docs/dev/firebase/firestore.rules`。
- 通知・承認・管理画面: Google Apps Script（`tools/notify-gas/`）。新しい申請は管理者にメール（承認・却下のリンク付き）、自動承認の一覧にある Google アカウントは即承認、承認したら本人にメール。管理画面（Apps Script のウェブアプリ、管理者だけが開ける）で一覧・Twitter・コメント・承認・却下。Twitter とコメントは Firestore の `admin_notes/{uid}`（本人には見えない）。管理画面の URL は docs/collaborators.json の admin_url に入れるとまとめページにリンクが出る。設定手順は同フォルダの README.md。2026-10-26 に設定済み（ルール更新・マニフェスト・setup・ウェブアプリ。管理画面のエラーなし。URL は admin_url）。通知メールは作った人のアカウントだけに送る（3人全員には送らない・2026-10-26 決定）。管理画面は作った人だけでログインしたブラウザで開く。
- これは「入口の扉」で、パッチなどのファイル自体は URL を知っていれば見られる（GitHub Pages の仕組み上）。ユーザーは了解済み。
